02 — Before you touch a screwdriver

Three things that save a bad night

⚡
Flash the BIOS first — with no CPU installed

Ryzen 9000 (Zen 5) needs a recent BIOS. This board has Q-Flash Plus, which updates the BIOS using only the PSU and a USB stick — no CPU, RAM, or GPU required. Doing this before installing the chip removes the most common "it won't post and I don't know why" failure. Steps are in the build order.

🖥️
No graphics card — and you don't need one

The Ryzen 7 9700X has a built-in GPU, so the motherboard's HDMI/DisplayPort outputs work for setup and for a headless server. (Only exception: if the box model number ends in F, that chip has no graphics and would need a GPU. The 9700X is not an F chip.)

📏
The 240mm radiator mounts on the internal fan-wall

This chassis takes up to a 360mm rad, so the 240mm fits with room to spare. In a 4U it mounts on the middle fan-wall where the three 120mm fans pre-install — not the top like a tower. Test-fit the radiator and check the hoses reach the CPU before final screws. (Confirm the exact bracket holes against the Rosewill manual — listings vary slightly.)

03 — Assembly

Build order

Roughly 2–3 hours for a first build. Build the core on the motherboard box first and bench-test it before it ever goes in the chassis — far easier to troubleshoot in the open.

Prep

Set up clean and grounded

Flat non-carpet surface, good light, a #2 Phillips. Touch the bare PSU case to discharge static (or wear a strap). Keep the boards in their anti-static bags until needed. Have a USB stick (8GB+) and a second computer to make the BIOS/OS media.
BIOS · do this first

Q-Flash Plus the motherboard

  • On the second PC, download the latest BIOS for "B650 Gaming X AX V2" from Gigabyte's support page.
  • Unzip, rename the BIOS file to GIGABYTE.bin (the included renamer tool does this), put it on a FAT32 USB stick.
  • With the board out of the case: connect only the PSU 24-pin and 8-pin CPU power. Plug the USB stick into the rear Q-Flash Plus port.
  • Press the Q-Flash Plus button. The LED blinks while flashing (a few minutes) and stops when done. Do not cut power. No CPU or RAM is installed yet — that's expected.
Core · on the bench

CPU into the socket

Lift the AM5 retention lever. Match the gold triangle on the CPU corner to the triangle on the socket. Drop it in — it seats with zero force. Lower the lever (firm, not forced). Save the plastic socket cover.
Core · on the bench

RAM in slots 2 & 4

For a 2-stick kit, use the second and fourth slots from the CPU (labeled A2/B2) for dual-channel — check the board silkscreen. Open the clips, line up the notch, press both ends until they click. Firm pressure is normal.
Core · on the bench

NVMe SSD into M.2 slot 1

Use the top M.2 slot (CPU-connected, fastest) for the boot drive. Lift the thermal heatsink, seat the drive at ~30°, push down, secure with the screw or latch, peel the thermal pad film, replace the heatsink.
Core · on the bench

Mount the AIO pump & apply paste

  • Fit the Arctic AM5 mounting hardware (the stock AMD backplate stays on the board).
  • Apply the included MX-6 — a pea-sized blob or small X; the pump spreads it.
  • Seat the pump, tighten the screws a little at a time in a cross pattern so it seats evenly. Don't fully torque one corner first.
  • Leave the radiator loose for now — it gets mounted in the chassis.
Test · before the case

Bench POST & enter BIOS

  • Connect 24-pin, 8-pin EPS, the AIO pump/fan PWM, and a monitor to the board's HDMI/DisplayPort.
  • Power on (jump the two PWR_SW pins with a screwdriver, or use the case button temporarily).
  • First boot runs memory training and can take 1–several minutes of black screen, even a reboot or two. This is normal AM5 behavior — wait it out.
  • Get into BIOS, confirm it sees the CPU, all 32GB RAM, and the SSD. Power down. Now it's worth moving into the case.
Chassis

Board into the 4U

Install the I/O shield (if not pre-attached to the board), set the brass standoffs to the ATX pattern, lower the board onto them, and screw it down. Don't overtighten.
Chassis

Radiator, fans & airflow

  • Mount the 240mm radiator + 2 fans on the front/mid fan-wall; route hoses to the pump.
  • Set fans as front-to-back intake through the rad so the rack pulls cool air across the board.
  • Use the 3 stock 120mm fans as exhaust / extra intake to keep a clean front-to-back path.
Chassis

PSU & cabling

The RM1000e is fully modular — only attach the cables you need: 24-pin, 8-pin EPS (CPU power, top-left of board), and SATA power if you add drives. No PCIe/GPU cables. Tuck the rest away.
Chassis

Front-panel headers

  • Power switch / reset / power LED / HDD LED → the F_PANEL header (check the board manual pinout).
  • Front USB 3.0 → the 19/20-pin USB 3.2 Gen1 header.
  • Front USB-C → the board's internal USB-C (Type-C / Key-A) header.
  • AIO ARGB lead → a 3-pin 5V ARGB header (not the 4-pin 12V RGB).
Chassis

Drives (optional, now or later)

The chassis holds 2× 3.5" + 3–4× 2.5" (verify the bay count on the unit). Mount any SATA drives, run SATA data to the board and SATA power from the PSU. The boot NVMe alone is enough to get running.

04 — First real boot

BIOS settings to set once

Boot into BIOS (tap Delete at power-on) and set these before installing the OS:

Enable EXPO

Turn on the EXPO profile so the DDR5 runs at its rated speed instead of a slow default. It may reboot and re-train memory once — normal.

Confirm boot device & fan mode

Set the NVMe as the boot drive. Set the CPU fan/pump header to PWM; a "Silent" or custom fan curve keeps it quiet under a light server load.

Set power-on behavior

For a server, set "AC Back / Power-on after power loss" → Always On so it restarts itself after an outage once the UPS battery is exhausted.

05 — What to run on it

Pick an OS for the job

A suggestion for each direction. If you're unsure, start with the recommended one — it can become all the others by running them as virtual machines.

Recommended
Proxmox VE
Do-everything homelab base

Free, open-source virtualization. Run multiple isolated VMs and lightweight containers on one box — spin up a NAS, a media server, and a dev box side by side, snapshot them, and roll back mistakes. With 8 cores and 32GB, this hardware is a great fit.

  • Install to the NVMe; add HDDs later as a storage pool
  • Manage everything from a browser on another machine
  • Pass the iGPU to a media VM for hardware transcoding
  • Best choice if Chris wants to experiment without commitment
TrueNAS SCALE
Storage / NAS first

Purpose-built network storage with ZFS, shares, and app plugins. Great if the main goal is a central file/backup server.

  • Heads-up: this chassis holds only 2× 3.5" + a few 2.5" — fine for a modest NAS, not a big bulk-storage array
  • Add matched HDDs in a mirror for redundancy
  • Can also run apps/containers, but it's storage-led
Debian + Jellyfin/Plex
Media server

Bare-metal Linux running a media stack in Docker. The 9700X iGPU handles hardware transcoding well.

  • Jellyfin (free) or Plex; add the *arr apps in Docker
  • Enable VAAPI transcoding on the AMD iGPU
  • Wire it on 2.5GbE for smooth 4K streaming
Ubuntu Server LTS
General Linux / Docker host

The familiar, well-documented default. A clean base for self-hosted apps, dev work, and Docker — no virtualization layer to learn.

  • Pick the LTS release for 5 years of updates
  • Install docker + a reverse proxy (Caddy/Traefik)
  • Easiest path if Chris just wants "a Linux server"

06 — Power & protection

Wire up the UPS

The CyberPower CP1500PFCLCD does two jobs: it rides through short outages, and it tells the server to shut down gracefully before the battery dies — so no corrupted filesystems.

Plug into the right outlets

Put the PC and monitor on the battery+surge outlets (one half of the back is surge-only — skip those for the critical gear). Its pure sine-wave output is the type the Corsair's active-PFC PSU wants.

Connect the USB data cable

Run the bundled USB cable from the UPS to the server. That's how the OS reads battery status and triggers shutdown.

Install the shutdown software

  • On Linux, use NUT (Network UPS Tools) with the usbhid-ups driver, or CyberPower's PowerPanel for Linux.
  • On Windows, use CyberPower PowerPanel.
  • Use only one — NUT and PowerPanel fight over the USB device.
  • Set a rule like "shut down when ~5 minutes of runtime remain."

Test it

With everything running, pull the UPS wall plug. The server should keep running on battery, then auto-shut-down at your threshold. At this build's ~150–250W draw, expect roughly 20–40 minutes of runtime — plenty for a clean shutdown.

07 — Questions that come up

FAQ

Will the original DDR4 RAM work?
No. This board is AM5 / DDR5 only — DDR4 is keyed differently and physically won't seat. The XSKY DDR5 kit is the right replacement. Hang on to the DDR4 for a different (AM4/Intel DDR4) build or resell it.
Do I need a graphics card?
No. The Ryzen 7 9700X has integrated graphics, so the motherboard's HDMI/DisplayPort outputs work for install and console. A server runs headless anyway. (You'd only add a GPU for gaming, heavy GPU compute, or if the chip were an F model with no graphics — the 9700X isn't.)
Why flash the BIOS before installing the CPU?
Ryzen 9000 needs a recent BIOS; an older one may not recognize the chip, leaving you with a no-boot you can't diagnose. Q-Flash Plus updates the BIOS with just the PSU and a USB stick — no CPU needed — so you eliminate that risk up front. Five minutes now saves an evening later.
First boot is a black screen for a minute+. Did it break?
Almost certainly not. AM5 boards run memory training on the first boot with new CPU/RAM — black screen for 1–several minutes, sometimes a reboot or two, occasionally a DRAM debug light. Don't cut power. It caches the result, so later boots are fast.
Does the 240mm cooler fit? Should it have been a 360?
The 240mm fits comfortably — the chassis supports up to 360mm. A 360 would cool marginally better, but the 65W 9700X is easy to cool and the 240 is plenty, especially with good front-to-back rack airflow. Mount the radiator on the internal fan-wall and confirm the hoses reach the pump before final screws.
Isn't a 1000W PSU way too big?
It's generous — this build draws roughly 150–250W. That's fine: the PSU runs cool, quiet, and efficient at low load, and you've got huge headroom to add drives or a GPU later. No downside beyond cost already spent.
How long does the UPS last, and what does it actually do?
At this load, expect roughly 20–40 minutes on battery (an estimate — runtime climbs steeply at lighter loads). Its real value isn't long runtime; it's the automatic graceful shutdown over USB so an outage never corrupts your data. Configure shutdown at ~5 minutes remaining.
Can I add more storage later?
Yes. The board has two more M.2 slots and several SATA ports, and the chassis has 2× 3.5" + a few 2.5" bays. Start with the 2TB NVMe boot drive and expand when you need it.
Does a 4U go straight in a rack?
It needs either rack rails/shelf or a sturdy surface — a loaded 4U is heavy, so don't hang it from front screws alone. Also check the chassis depth against your rack before mounting. It runs fine sitting on a shelf too.
RGB on a server — really?
The Arctic AIO and the RAM have addressable RGB. Harmless. If you'd rather it be dark in a closet, set it to off/static in the BIOS or lighting software. Functionally irrelevant either way.
Wired or Wi-Fi?
Use the 2.5GbE wired port for a server — faster and rock-stable. The board's Wi-Fi 6E is a nice fallback, but a stationary rack server should be on a cable.
