Set up your workspace

⏱ About 45 minutes 🛠 You'll install real software today

Before you start: the account

Claude Code needs a Claude account with a paid plan — it's included in the Pro plan and up. The free plan doesn't include Claude Code.

  1. Go to claude.ai and create an account (or sign in) — email or Google sign-in both work.
  2. If you're not on a paid plan yet, upgrade to Pro at claude.ai/pricing. Pro is plenty for this course.
Cost a problem?

If the subscription is a real barrier for you right now, tell your HAND contact or press "I'm stuck" and say so. HAND exists to remove exactly this kind of obstacle — we'd rather help than lose you at step one.

Install the Claude desktop app

The desktop app is one download — Claude Code lives inside it.

On a Mac (macOS 13 or newer)

  1. Download: Claude for macOS (works on both Intel and Apple Silicon).
  2. Open the downloaded .dmg file and drag Claude into your Applications folder.
  3. Open Claude from Applications. If macOS asks "are you sure you want to open this?", click Open — it's the normal check for downloaded apps.

On Windows (Windows 10 or 11)

  1. Download: Claude for Windows (most PCs — if you have a newer ARM laptop, use this version instead).
  2. Run the installer and follow the prompts.
  3. One extra step on Windows: install Git for Windows (a free helper tool Claude Code relies on). Accept all the default options in its installer — you never have to touch it again. Then restart the Claude app.

When the app opens, sign in with your Claude account — it will pop open your browser to confirm, then bring you back.

Find the Code tab

At the top of the Claude app you'll see tabs — Chat, Cowork, and Code. Chat is the familiar chatbot. Click Code. That's where this entire course happens.

The first time in, Code asks two setup questions:

  • Where should Claude work? Choose Local — meaning "on this computer." (The other options — Cloud, SSH — are for later in your journey.)
  • Which folder? That's our next step ↓

Make your practice folder

Claude Code always works inside one folder you choose — its workshop for the session. It reads and changes things in that folder, not all over your computer. Let's make a practice one:

  1. On your Desktop, create a new folder (right-click → New Folder) and name it claude-practice. Lowercase with a dash, no spaces — some tools are fussy about spaces in names, so this habit prevents weird problems later.
  2. Back in the Claude app, click Select folder and choose the claude-practice folder you just made.
Habit worth keeping

One project = one folder. When you start your real app in Module 05, it gets its own fresh folder. Never point Claude at your whole Desktop or Documents — keep its workshop tidy and contained.

The 90-second interface tour

You don't need to memorize this — just know what exists, so nothing surprises you:

  • The prompt box (bottom) — where you type instructions to Claude. Press Enter to send.
  • The conversation (center) — Claude narrates what it's doing as it works: reading files, proposing changes, running commands.
  • The mode selector (next to the send button) — controls how much Claude asks before acting. It should say Manual right now: Claude asks before every change. Leave it there for now; Module 04 explains the other modes.
  • The model dropdown — which Claude brain to use. The default is fine; don't overthink it.
  • The sidebar (left) — your sessions. The + button starts a new one. You can run several in parallel someday; one at a time is right for now.
  • The stop button (square, appears while Claude works) — interrupts immediately. You are always allowed to press it.

Two power panes you'll meet later in the course:

  • Diff viewer — click the little change stats (like +12 −1) to see exactly what changed in a file, green for added, red for removed.
  • Browser pane — the desktop app can show your app running inside the Claude window, and Claude can see it too. This becomes magic in Module 06.

Say hello

Let's confirm everything works. Copy this into the prompt box and press Enter:

Copy into Claude Code 
Hi! I'm brand new to Claude Code and this is my practice folder. In one short paragraph: introduce yourself and tell me what you can see in this folder right now.

Claude will look around (the folder is empty — it will say so) and introduce itself. That's it: you just directed an AI on your own computer. If instead you hit an error or something looks broken, that's a perfect first use of the I'm stuck button.
