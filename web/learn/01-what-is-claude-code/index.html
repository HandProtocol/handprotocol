What is Claude Code?

⏱ About 25 minutes 🛠 Reading only — install comes next module

Claude the chatbot vs. Claude Code

You may have used Claude (or ChatGPT) as a chatbot: you type a question, it types an answer. Helpful — but everything it "makes" is trapped in the chat window. If it writes you a recipe app, it hands you a wall of text and wishes you luck.

Claude Code is different in one enormous way: it can actually do things on your computer. It can create files, edit them, organize folders, run programs, and check its own work. When Claude Code builds you a recipe app, the app exists — real files, on your machine, that open in your browser.

A decent mental model:

  • Chatbot Claude is a brilliant friend on the phone. Great advice, but you have to do everything yourself.
  • Claude Code is that same friend sitting at your keyboard, hands on the keys, asking "want me to just do it?" — while you watch and stay in charge.

What it can do

  • Create and edit files — web pages, documents, images' layouts, whole project folders.
  • Run commands — the technical chores programmers do in a terminal, like starting a test server or installing a tool. You don't need to know the commands; Claude does.
  • Build working software — websites, small apps, tools, games. It writes the code, you describe the result you want.
  • Fix its own mistakes — show it an error and it will usually diagnose and repair it.
  • Explain anything — every file, every step, at whatever level you ask for. "Explain that like I've never coded" is a completely legitimate instruction, and you'll use it a lot.

People call this kind of tool "agentic" — a fancy word meaning it doesn't just answer, it takes a goal and works toward it in steps: reading files, making changes, checking results, adjusting. You'll watch it narrate as it goes.

What it can't do (and where it struggles)

Being honest about the edges will save you frustration:

  • It can't read your mind. Vague ask, vague result. "Make it better" gets you a coin flip; "make the headline bigger and the background cream" gets you exactly that. Module 04 trains this muscle.
  • It can be confidently wrong. Sometimes it will say "done!" and the thing is not quite right. That's why you always look at the result — the course builds this habit early.
  • It forgets between sessions. Each new conversation starts fresh. There are simple tools for continuity (a notes file called CLAUDE.md — Module 08), but assume a new session knows nothing.
  • Usage has limits. Paid plans include a generous allowance that refills on a schedule. Long, rambling sessions use it faster — another reason the tidy habits in Module 04 matter.
Treat Claude Code like a talented, fast, slightly overconfident collaborator — not an oracle. Trust, then verify.

Why it's safe to let it work: permissions

"An AI that can change files on my computer" sounds scary until you see the safety model. By default, Claude Code asks before it touches anything:

  • When it wants to edit a file, it pauses and shows you exactly what it wants to change — old version and new version side by side (this view is called a diff; additions show green, removals show red). Nothing happens until you press Accept.
  • When it wants to run a command, it shows the command and waits for your OK.
  • If you press Reject, nothing changes, and Claude asks how you'd like to proceed instead.
  • There's always a stop button to interrupt it mid-task.

Later, when you trust the flow, you can loosen this (a mode that auto-accepts routine file edits). For this course we start in the default Manual mode, where you see and approve everything. Best training wheels ever invented.

Ten words you'll hear constantly

WordPlain meaning
FileA single document on your computer — a page, an image, a list of code.
FolderA container for files. Your app will live in one folder.
ProjectThe folder holding everything for one thing you're building.
CodeText written in a language computers follow. You'll read a little, write almost none.
SessionOne conversation with Claude Code. New session = fresh memory.
PromptWhat you type to Claude — your instruction or question.
DiffThe before/after view of a change Claude wants to make. Green added, red removed.
TerminalThe text window where commands run. Claude drives it so you don't have to.
ContextEverything Claude currently "has in its head" this session. It fills up; Module 04 covers keeping it tidy.
DeployPutting your app on the internet so anyone can visit it. Module 07.
