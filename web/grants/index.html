How this tracker works

Three states, one source of truth.

A grant moves through four states: discovery (we found it, haven't decided yet), drafting (we're writing the application), submitted (in their queue), and decided (awarded, declined, or withdrawn). The HTML below is a rendered view; the authoritative record lives in funding/grants/<slug>.md.

The /grants skill in Claude Code handles all four phases: register a new grant from a URL, run a fit assessment, draft application answers from HAND's mission and governance docs, and log follow-up. See ~/.claude/skills/grants/SKILL.md.

    Why this is a fit

    HAND's Sovereign Reciprocates workstream commits to building custom open-source agent systems for each Reciprocate group, owned by the group itself. Arcee's Trinity-Large-Thinking is Apache-2.0 weights, post-trained with agentic RL and extended chain-of-thought — exactly the agent-loop substrate we'd otherwise have to fine-tune ourselves. Credits move us from one-off prototypes to evaluable multi-turn runs without paying retail inference.

    What we'd build with the credits

    • Sovereign Reciprocate agent prototypes. Three pilot Reciprocate groups (healers, impact-driven business, grassroots collective) each get a custom Trinity-Large-Thinking agent harness covering intake, scheduling, ledger entries, and bounty matchmaking. Open-sourced as a reference template.
    • Eval harness for "sovereignty-aware" agents. We're already drafting the AI-EVAL framework (AI-EVAL-FRAMEWORK.md); credits let us run the eval against Trinity-Large-Thinking as the reference open-weights baseline.
    • Agentic onboarding flow for Mystic Hearts. Mystic Hearts is the first live Reciprocate-group product (Next.js + Supabase). Trinity drives the practitioner-intake agent, which handles a multi-turn conversation, populates the ledger, and flags reviewer cases.

    Token ask

    200M–500M tokens. Three concurrent agent workstreams, multi-turn (avg 8 turns × ~6K context), plus eval runs and replay testing. The bracket fits without overclaiming. We'll request 500M and accept a partial award gracefully.

    Resolved before submission

    • Framing: lead with Sovereign Reciprocates; Mystic Hearts is named as the first concrete instance.
    • Applicant: Russell Herod (HAND Protocol Foundation), aka koH.
    • Eval publication: aggregate results and the harness, yes — individual practitioner sessions stay private unless that practitioner opts in.

Operating principles

How we decide whether to apply.

  1. Mission alignment first. Does the funder's stated intent overlap with HAND's resource-pool model or the Sovereign Reciprocates workstream? If we'd have to bend our description to fit, we pass.
  2. Cost of application vs. expected value. Small rolling-review credit grants are worth a 2-hour write-up. Federal grants requiring 40 hours of narrative and matching funds we don't have are not, yet.
  3. Strings attached. Reporting cadence, IP claims, exclusivity clauses, naming requirements. If they conflict with our open-source defaults or the Sovereign Reciprocates sovereignty principles, we decline regardless of dollar size.
  4. Honest scope. We ask for what we'll actually use, in the bracket below "obviously too much." Partial awards are a feature, not a failure.
