# KC Collective: image slots and credits

Every photo on the site is a hot-linked Unsplash placeholder chosen to match Kimberly's mood board (iridescent florals on water, bubbles, pastel pinks and aquas, candid photos of women gathering). They are free under the Unsplash License and may be used as-is, but the plan is to swap each slot for the collective's own photography before launch.

## How to replace a slot

1. Save the new photo into this folder (for example `assets/hero-floral.jpg`, 2000px wide, under 400 KB).
2. In `index.html` (and in each `styles/<direction>/index.html` you want to keep), find the slot's current Unsplash URL (listed below) and replace it with `assets/<file>` (`../../assets/<file>` inside `styles/`).
3. Keep the `alt` text honest to the new picture.

Before launch, also download the Unsplash files you keep into this folder so the site does not depend on a third-party CDN (see HANDOFF.md).

## Hot-link parameters

Each `<img src>` appends Unsplash's resizing parameters, e.g. `?w=1600&q=80&auto=format&fit=crop` (add `&h=` for a fixed crop). The base URL is the part before `?`.

## Brand mark

`kc-icon.svg` is a placeholder favicon: thirteen points around a circle (a constellation, thirteen moons). Replace with the collective's logo when there is one.
