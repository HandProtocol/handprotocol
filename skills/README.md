# HAND Skills

These are the repo-local HAND skills. The actual Codex-triggered skill files live in `.claude/skills/`, and this directory is the visible index for the workspace.

## Active Skills

- `hand-public-surfaces`, public website, discovery, governance, redirects, and public instrumentation.
- `hand-command-center`, the internal Command Center app, dashboard, projects, feedback, page review, Reciprocates, and grants UI.
- `hand-reciprocates`, Reciprocates vocabulary, group-scoped workflow, and Sovereign Reciprocates.
- `hand-funding-grants`, foundation raise copy, grant markdown, funder research, and funding UI.
- `hand-biz-pitch`, local-business outreach, demo sites, and pitch pages.
