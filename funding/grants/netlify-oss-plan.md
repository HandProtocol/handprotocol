# Netlify · Open Source Plan

## TL;DR

Lowest-effort win of the infra batch. HAND is already on Netlify (handprotocol.org). Netlify's OSS Plan provides free production deploys, monthly build credits, and unlimited team seats for qualifying OSS / public-good projects. Submit a support ticket; decision in days.

## The program

> "For open-source maintainers and public-good organizations."

What's included (from the OSS Policy page):
- Free production deploys
- Monthly build credits
- Unlimited team members
- Qualifying OSS or public-good org status

## Fit assessment

**Score: 5/5.**

- **Direct quota relief on existing deployment.** Zero migration cost — we're already deployed.
- **OSS + public-good org status.** HAND publishes governance, financials, and code openly. Edge functions, intake function, mailing-list integration are all in the public repo.
- **No 501(c)(3) required.** The "public-good organizations" clause covers HAND directly.

## Application answers — draft

Submit via Netlify support. Suggested ticket content:

---

**Subject:** Open Source Plan request — handprotocol.org (HAND Protocol Foundation)

Hi Netlify team,

We're requesting an upgrade to the Open Source Plan for the `handprotocol` project (project ID `0d46269a-789a-4e42-a00e-7f30e79c5869`).

HAND Protocol Foundation is a pre-501(c)(3) public-good organization filing in Austin, TX. We run a curated skill-and-resource pool for healers, impact-driven entrepreneurs, and grassroots organizations. Everything we build is open source:

- Public repo: github.com/HandProtocol/handprotocol
- Live site: https://handprotocol.org
- Governance, discovery research, and financials all published openly at /governance and /discovery
- We use Netlify Edge Functions for an internal grants-tracker auth gate and Netlify Functions for our mailing-list intake (via Resend)

Our work qualifies under the OSS Plan's "open-source maintainers and public-good organizations" criteria. Happy to provide additional documentation as needed.

Thanks,
