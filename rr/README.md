# Reimagine Ranch

Reimagine Ranch (**RR**) is a developing piece of community land within HAND Protocol's
Reciprocate-community pattern — the same pattern proven first by [Mystic Hearts](../web/mystichearts/).
Where Mystic Hearts is a healing land growing a collective that heals, Reimagine Ranch is
**land being reimagined into shared community infrastructure**: built slowly, sustainably, and
with as much of the labor and material drawn from the community itself as possible.

HAND's role here is the same quiet backend it provides everywhere — coordination, credit-loops,
documentation — not a product bolted onto the land.

> **Status (2026-05-29):** Early. First build project scoped. No public marketing.
> This workspace is internal until the founder approves a public surface.

## First project — Compost sawdust latrine

A raised, accessible **two-stall composting (sawdust / dry-cover) latrine** with a ramp and a
covered patio. It is deliberately the first build because it is:

- **High-leverage:** any gathering on the land needs sanitation before anything else.
- **Low-risk, high-teaching:** a contained build that lets the community credit-loop find its feet.
- **A model of the values:** waterless, off-grid, nutrient-cycling, locally sourced.

Scope locked for v1:

- **Two stalls** — one ADA-accessible, one standard.
- **Raised platform** (deck) above grade — clearance for the compost vault/bins and drainage.
- **Ramp** to the raised level at an accessible slope, with a mid landing.
- **Covered patio / porch** across the front as the shared approach and a place to wait.
- **Passive vent stacks** per stall for odor and moisture control.

System type, exact capacity, and finish tier carry open decisions — see
[`research/compost-latrine.md`](research/compost-latrine.md) §Decisions.

## Modeling decision: Blender (not CAD)

For massing, siting, ramp-slope verification, and shareable visuals we model in **Blender**
first. It's faster to iterate the *form* and produce something the community can actually look
at and react to. A precise cut-list / board-by-board CAD model (FreeCAD) comes **after** the
massing and dimensions are approved — that's a fabrication step, not a design step.

The Blender scene is generated by a committed Python script
([`blender/compost_latrine.py`](blender/compost_latrine.py)) so the model is reproducible and
version-controlled: change a dimension in the script, re-run, get an updated `.blend` and render.

```bash
# regenerate the scene + render from the repo root
blender --background --python rr/blender/compost_latrine.py
```

## How RR fits HAND

- **Reciprocate pattern:** RR is the *second* worked instance of the community-land pattern
  (Mystic Hearts is first and remains the only public one). Do **not** name RR publicly as a
  confirmed Reciprocate community until the founder approves — internal only for now.
- **Credit loop:** community labor on the build earns credits, same mechanism as the Airstream
  build-labor loop. The latrine is the pilot for RR's credit ledger.
- **Grants:** RR's sustainable-build story (waterless sanitation, nutrient cycling, local
  sourcing, accessibility) is grant-relevant — but route through the founder before any external
  use, exactly as with Mystic Hearts.

Voice + routing rules live in the `/hand-project-rr` skill.
