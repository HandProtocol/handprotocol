# Proposal — Lumber Procurement for the Compost Latrine (Reimagine Ranch)

**Date:** 2026-05-29 · **Prepared for:** koH / HAND · **Status:** Internal, decision-ready
**Companion:** [`lumber-supply.md`](./lumber-supply.md) (takeoff, suppliers, pricing, lead times) ·
[`compost-latrine.md`](./compost-latrine.md) (design + §7 dimensions)

---

## 1. Recommendation (one paragraph)

Build the **pilot latrine on Path A** (community-weekend tier) with a **hybrid sourcing split**:
buy hidden structure and commodities off-the-shelf for speed and cost, and buy the **visible
cedar from Harvest Lumber Co.** — Austin salvaged urban trees with documented provenance — so the
build *looks like* and *can be told as* what RR is. Order the **metal roof in week 0** (longest
lead) and **reserve/dry the local cedar in week 0** (second-longest). Frame to Path-B geometry
(deck height, vault bays, stack routing) so the structure can be upgraded in place later without a
rebuild — **build once, upgrade in place.**

---

## 2. Sourcing plan (who supplies what)

| Bucket | Buy from | Why |
|---|---|---|
| **Visible cedar** — siding, crown vent, fascia, character trim | **Harvest Lumber Co.** (+ Southwest Trading Post / Berdoll for volume) | Salvaged local provenance = the mission + the grant photo |
| **Clean cedar runs** — decking, rail caps | **Eastside Lumber / TimberTown** (Western Red Cedar, in stock) | Long, straight, dry, fast |
| **Hidden structure** — PT sills/beams/joists, SPF studs, rafters/purlins | **McCoy's / Builders FirstSource** | Cheap, code-known, same-week |
| **Fasteners/hangers/brackets** (SS or HDG) | Same chains | Off-the-shelf |
| **Roof** — exposed-fastener ag-panel (pilot) | Texas metal supplier (order early) | Rainwater-clean, budget, ~4 wk lead |
| **Foundation** — precast pier blocks (pilot) | Any yard | No pour, reversible, DIY |
| **Finish** — tung/linseed oil, gravel | Chains | Commodity |

---

## 3. Phased procurement (gated by the two long-lead items)

1. **Week 0 — commit + long poles.** Lock design/path. **Order ag-panel metal roof** (~4–8 wk).
   **Reserve local cedar and start drying** if green (~3–8 wk), or buy already-dried. Order the
   rainwater cistern now if the upgrade is in scope (it ships, doesn't build).
2. **Week 1 — commodities.** Buy PT framing, SPF studs, fasteners, hangers, pier blocks, gravel,
   oil. All same-week. Begin site prep + set piers.
3. **Weeks 1–3 — structure dollars working.** Deck + walls go up on in-stock material while the
   roof and cedar are in transit/drying.
4. **Weeks 4–5 — roof arrives.** Install roof + vent stacks.
5. **Weeks 5–6 — cedar ready.** Side, crown, fascia, ramp/stair/rails.
6. **Weeks 6–8 — finish.** Skirt/hatches, fixtures, signage, oil; first use.

*(Full week-by-week with build sessions is in `lumber-supply.md` §5.)*

## 4. Budget ask

| Scenario | Materials | When |
|---|---|---|
| **Pilot — Path A, 3×3** (recommended) | **$2,500–3,500** | now |
| Pilot — Path A, **2×2** (compact) | **~$1,800–2,500** | alt |
| + Rainwater upgrade (cistern + 2–3 showers) | **+$1,800–2,800** | now or later |
| Path B upgrade-in-place (screw piles, standing-seam, finished cedar) | **delta to ~$6,000–9,000** | when grant-funded |

Single biggest swing is the **foundation** (precast DIY ~$300 of material vs screw piles
~$2.7–4.5k installed) and the **roof** (ag-panel vs true standing-seam). The recommendation keeps
both on the cheap/DIY side for the pilot and earmarks the upgrade for grant dollars.

## 6. Why this is the RR-right way to buy wood

It spends the least money on the most visible, most fundable thing (salvaged local cedar with a
documented story), keeps the structure cheap and reversible, defers the expensive choices
(screw piles, standing-seam) to grant dollars without a rebuild, and sequences the buy so the
**lead times — not the volunteers — set the calendar.** Build once, source local, upgrade in place.
