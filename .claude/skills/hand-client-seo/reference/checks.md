# The checks

Generated by `seo.mjs checks --md` from `scripts/lib/checks/` (86 checks). `gate` = part of the launch gate: a fail there blocks `seo.mjs test --gate`.

Severity: **fail** keeps a page out of search or misleads people; **warn** costs ranking or clicks; **info** is polish. Who acts: HAND (default), the owner, or at the domain move; set per finding.
