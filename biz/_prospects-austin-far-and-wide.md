## How to work this list

Pick a row, copy its maps link, and run the pipeline from the repo root:

```
npx tsx command/scripts/build-lead.mts "<maps-url>"
```

That scrapes the place, writes biz/<slug>/lead.md, registers it on the
Develop board, and builds the demo plus the gated pitch page.

Remember the bar these rows already cleared: no real website (none or
social-only), 4.2+ rating, 15+ reviews, phone on the Maps card. The phones
are unconfirmed, so spot-check the digits before a caller works a lead, and
verify the business name on the demo before pitching (the scraper can
mislabel). The 908 errored checks from this run are a recheck pool for a
future pass, there are more prospects hiding in there.
